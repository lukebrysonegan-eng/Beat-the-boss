# Ember Forge

A tap-to-earn forge simulator. Strike the anvil for coins, buy upgrades and super powers, then walk into each boss's room and beat it.

## Play

Open `index.html` in any browser. Progress saves in that browser.

## Controls in a boss room

- Move: WASD or arrow keys (on a phone, drag on the left half of the room)
- Attack: Space, click, or tap the right half of the room
- Dash: Shift
- Super powers: number keys 1–9 and 0
